# 一致的表单体验

业务表单既要保持字段外观一致，也要处理阅读、编辑、校验和确认。Cedar 通过字段外壳与 Form 的展示约定组合这些能力。

## 先完成一张业务单

1. 保持任务名为空，点击“校验并预览”，观察必填提示。
2. 点击“填入演示数据”，进入预览；返回修改，再进入预览。
3. 勾选“模拟下一次保存失败”，确认提交。失败时草稿保留，已提交记录仍为空。
4. 点击“重试提交”，核对成功记录；继续编辑时核对上次记录没有被草稿覆盖。
5. 点击“重新演示”，恢复到初始状态。

<demo src="../../src/form/__demos__/task-workflow.vue"></demo>

这个例子组合组件能力实现业务流程；保存用本地延迟模拟，实际接口由应用接入。字段校验与服务端保存失败是两种不同结果。

## 一组字段，一起比较

切换五档尺寸和三种变体，观察 Input、Select、日期时间字段的高度、前后缀和长标签。多行内容按内容撑高。

<demo src="../../src/field-decorator/__demos__/control-sizes.vue"></demo>

## 从阅读进入编辑

1. 在下方选择 click 或 dblclick，按对应方式进入字段编辑。
2. 修改内容后取消，核对已保存模型；再修改并确认，核对模型更新。
3. 切换纯阅读状态，观察普通字段与单项覆盖字段的表现。

<demo src="../../src/form/__demos__/field-presentation.vue"></demo>

## 与其他实现对照什么

使用相同字段和校验规则，比较样式配置的重复程度、阅读态渲染方式、确认与取消的数据流，以及单字段覆盖是否需要额外封装。记录完成这个场景所需的业务代码与交互结果。
