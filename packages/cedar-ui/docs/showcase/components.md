# 逐组件对照

按开发任务归类组件：先认识基础与布局，再进入输入、选择、表单、数据管理和业务场景。每个组件都列出当前 Cedar 的展示重点、可操作示例，以及其他组件库的参考案例。

Vue 组件库用于比较使用与交互，React / Angular 组件库用于借鉴场景和示例组织。参考链接固定到工作区源码版本；“相关组合”表示职责相近的组合示例，不能据此认定对方缺少该能力。

## 功能点与增量

展开“相似功能点逐项对照”，可查看已有示例、文档依据和待核验增量；“值得补充的重要内容”按当前分类列出优先级、参考案例和验收重点。待核验表示尚未找到对应专题示例，不直接等同于缺少能力。

## 示例阅读顺序

基础用法 → 尺寸、变体与状态 → 常用交互 → 异步数据 → 插槽与业务组合 → 边界和生命周期。表单字段与独立面板分别归类，避免将两种接入方式混为同一功能。

## 怎么判断优势

对相同数据、容器和操作步骤，比较接入配置、额外业务代码及操作结果。当前索引提供源码与示例内容对照；性能、兼容性和失败恢复等结论需要同环境运行验证。
