## Cedar × Maple. Two platforms, one architecture.

Cedar is the desktop counterpart to Maple. The two libraries align component APIs, interaction semantics and design tokens, so familiar patterns carry across platforms while each keeps the interactions its platform needs.

| | Cedar Design Web | Maple Design Mobile |
| --- | --- | --- |
| Platform | Desktop · mouse and keyboard | Mobile · touch |
| Components | Shared API and behavior conventions | Shared API and behavior conventions |
| Themes | Semantic tokens · brand themes · light and dark modes | Semantic tokens · brand themes · light and dark modes |
| Explore | You are here | [Visit Maple ↗](https://maple.show) |

## Start with Cedar

```shell
pnpm add @cedar-design/ui
```

See the [quick start guide](/en/guide/quickstart/) for setup, component imports and styles. For mobile applications, explore [Maple Design Mobile](https://maple.show).
