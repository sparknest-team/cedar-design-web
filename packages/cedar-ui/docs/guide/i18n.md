## 国际化

默认中文，其他语言设置如下：

```typescript
import { addI18nMessages, useLocale } from '@cedarjs/ui'

if (Env.getLanguage() !== 'zh-CN') {
  addI18nMessages({
    [Env.getLanguage()]: require('@cedarjs/ui/es/locale/lang/en-us').default,
  })
  useLocale(Env.getLanguage())
}
```
