## 组件配置

### Loading Props

| 属性 | 说明     | 类型   | 默认值 |
| ---- | -------- | ------ | ------ |
| type | 参数类型 | string | -      |

### Loading Events

| 事件名 | 说明           | 参数                          |
| ------ | -------------- | ----------------------------- |
| click  | 点击触发的事件 | `(event: MouseEvent) => void` |

### Loading Slots

| 插槽名  | 说明           |
| ------- | -------------- |
| default | 自定义默认内容 |
