## 圆角 Border Radius

用于设置元素的圆角。

可直接添加以下Class来使用 `border-radius` 样式。

- 点击Class可快捷复制
- Properties表示该Class设置的属性值
- Effective CSS 表示该Class最终生效的CSS属性
