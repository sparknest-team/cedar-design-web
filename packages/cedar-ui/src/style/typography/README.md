# 字体排版 Typography

样式工具类，用来设置文本与排版相关属性（Cedar PC 扩展；Maple 侧栏保留同名入口，能力见 Maple Typography 说明页）。

- 点击 Class 可快捷复制
- Properties 表示该 Class 设置的属性值
- Effective CSS 表示该 Class 最终生效的 CSS 属性
