# Design
- 各端保留独立源码；相同核心通过复制及校验门禁防漂移。
- 日期值为 Date | string | number；format 用于显示，valueFormat 用于模型和事件。无效字符串不得宽松纠正后提交。
- min/max 为包含端点的边界；disabledDate 与 disabledTime 接受 Date 与 start/end。规则在选择和确认时重新校验。
- 单值、范围、多选分别验证形状；范围必须完整且开始不晚于结束。单端锁定不得被排序破坏。
- 选择草稿 select 不代表 change。取消、外部重置、受控开合和重复确认均由统一事务处理。
- 两端原日历 / 滚轮局部状态仅负责绘制与导航，不负责公开模型提交。
- 全局多语言分别接入当前系统，组件展示文件不创建新的 locale 系统。
