# NavMenu scrollTo 续体归属

## 范围与原因

原6项有效基线中4项失败：旧请求未被新命令替代，禁用／停用后仍原生滚动。正常nearest定位及卸载后空注册表为原本通过的对照，不计缺陷。

## 既有行为收口

保留scrollTo(key): Promise<void>，无新API／Token。每次请求拥有独立代次；配置变化、停用和卸载逻辑失效旧续体。重新激活不重放。showOption通知后再核对，避免同步重入仍继续排旧工作。焦点与测量消费者尚未收口，不由本批推断通过。

## 验证边界

8专项及全部NavMenu45项通过；JSDOM真实组件／KeepAlive，非真实浏览器或原生动画证明。共享规范、两端指南、组件文档与逐组证据同步。
