# OverflowList layout and public contract

Clamp finite nonnegative minimum counts to available items, floor decimal counts, retain zero, and diagnose invalid numbers/enums. Recompute on props/content/container changes with identity-aware width caches and live DOM observation. Use logical CSS gap as extra spacing without mutating child margins. Keep hidden-item unmount semantics and measure in the same render tree, never a duplicate app. Document slots, notifications, SSR/measurement and instance types. Cedar only.
