# Message isolated reduced-motion policy

Both independent styles disable built-in decorative motion under reduce without relying on global ultra-short durations. Cedar cancels root/phase transitions and icon fades. Maple cancels fade transitions/displacement while preserving standalone horizontal/center translation used for static positioning.

No Token/default/API or business display deadline changes. Normal consumers and paired duration/easing overrides remain validated. Compiled preference selection does not prove native OS switching or child Icon behavior.
