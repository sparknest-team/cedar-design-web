# 对齐全量 CI 中发现的时间范围陈旧说明

两库当前 `getTimeCommitValue` 和 Maple 最近提交的范围顺序验证均禁止隐式交换端点：`showNextDay=false` 时倒序草稿不能提交，`true` 时保持原顺序提交；相等时间合法。Cedar 的早期 time-field-commit / time-value-contract 说明和一项文本输入测试仍写着自动排序，与当前实现不符。

本次不改变运行时或公开 API，将 Cedar 当前文档和文本输入测试对齐现行协议；补充两端回归，确认倒序的禁用小时和步长违规仍被拒绝，不能通过排序绕过校验。早期提案中的排序描述以本次澄清为准，不作为恢复自动排序的依据。
