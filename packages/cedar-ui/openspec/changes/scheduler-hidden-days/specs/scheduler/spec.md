# Scheduler 隐藏星期

- hiddenDays 默认 []，整数 0–6，去重，不可隐藏全部七天。非法组件配置警告并回退全显示；纯核心工具抛 RangeError。
- 周、月、议程过滤可见日期，单日/资源日程/资源时间线保持原语义。
- 月网格每行列数与可见星期一致，firstDayOfWeek 决定顺序，保持六周数据范围。
- range-change、导航跨度、数据模型和容量/冲突校验不改变。
- 跨隐藏日期日程显示可见片段，拖动按真实目标日期，保留完整持续时长。
- 配置变化取消进行中的拖动；议程无可见日程显示空状态。
- Demo 展示周末/周三开关、跨周末任务和视图切换。
