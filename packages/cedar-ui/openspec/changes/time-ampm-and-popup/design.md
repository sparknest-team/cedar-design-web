# AM/PM、步长与浮层切换
- Trigger 在捕获阶段判断外部点击，针对事件开始时的顶层浮层关闭；嵌套后代仍算内部点击，受控 open 仍由调用方决定。两端独立复制修复。
- Maple 现有 format=ampm 在滚轮上增加真实 AM/PM 列；24hr 保持原列布局。模型继续使用 24 小时字符串（不是格式 API 全面迁移）。12 AM=00，12 PM=12；禁用回调始终读取 0–23 小时。
- Maple 新增与 Cedar 同名的 step={hour,minute,second}。候选以 0 点为步长起点，12 小时只是显示转换，边界/禁用继续叠加。核心规则和测试独立复制。
- 同主题 demo：AM/PM、步长、多个时间字段、范围跨日。中间与右侧引用同一 Maple 文件。完整 format、模型类型和组件主体同源仍单独跟进。
