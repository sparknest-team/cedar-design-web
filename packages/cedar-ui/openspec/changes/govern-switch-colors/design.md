Solid tracks use content-secondary / content-brand / content-danger as identifiable control marks, paired with surface-default cutout text/thumbs. Thumb icons use content-brand. tonal unchecked uses surface-muted with content-secondary outline/thumb/text and opaque surface-default thumb icons (surface-muted is translucent in dark mode). Enabled errors reset all three parts to the solid-track palette. Disabled/loading suppress error without losing checked identity.

New public tonal-text-color and tonal-handle-color govern only tonal unchecked, non-error presentation (including disabled/loading). Existing text-color and handle-color retain solid-state consumers. Existing tonal-border-color continues to govern the unchecked outline and thumb. Explicit custom tracks require independently chosen foregrounds. CSS names differ by c/mp prefix only. Maple dark inherits semantic defaults.
