# Time private scrolling

Same-element replacement cancels its predecessor. Each owner-window frame is consumed once and cannot overwrite a replacement after cancellation or reentry. Private cancellation stops interpolation at its current position without submitting a selection. Nonpositive/nonfinite duration and reduced motion use the target without a new frame; dynamic reduce settles on the next live frame. Positive caller durations remain linear.

The component consumer must separately own the returned disposer and invalidate delayed eligibility on suspension/disposal;that integration is not certified by helper tests. No public component API or CSS Token is added.

Component acceptance adds current root/value/element checks after geometry,one-shot render continuation consumption and sync task invalidation on current input changes. Hidden/inactive/disposed or removed/disabled retained item commands are inert. New activation aligns current state without replaying old interpolation. Sixteen controlled consumer cases cover these paths;arbitrary same-item ref-callback reordering,native/OS/adoption and parallel panel integration remain separate.
