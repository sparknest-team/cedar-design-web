# Align VerificationCode independent source bodies

Complete Cedar's OTP API with Maple capabilities, then copy the completed body, props, types, styles and tests into Maple. Each library retains only its local Form and installation adapters.

Behavior changes: digit is the shared default; paste inserts at the current cell; disabled/readonly/IME are protected; controlled refusal restores native inputs. change reports whole-code proposals, finish reports complete proposals accepted during the current render cycle. Form notifications occur once per whole control. Public CSS uses four matching tokens; Cedar column-gap is removed.

Non-goals: shared runtime, compatibility aliases, schema validation and automatic server-side verification.
