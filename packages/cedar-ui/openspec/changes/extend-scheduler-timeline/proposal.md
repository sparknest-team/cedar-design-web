# Extend Scheduler timeline

Add native timeline scale selection and collapsible resource grouping while retaining existing day/week behavior by default. Expose pure time-axis and grouping helpers through the existing core entry. UI controls remain Cedar components.

Scope: hour/day scale, controlled/uncontrolled group expansion, resource labels fixed while scrolling, examples and compatibility tests. Work calendars, recurrence, virtualization and transactions are subsequent roadmap phases.
