@cedar-design/ui-vue

1.2.0

Minor Changes

  • #6 6620155 Thanks @sparknest-team! - Release the public packages together at 1.2.0 so applications can install matching versions.

  • #1 38eb17b Thanks @sparknest-team! - Replace CFormSection and Form.Section with CSection. Import Section and its types from the Section entry and rename c-form-section CSS overrides to c-section. Inside Form, Section retains the previous field layout and appearance.

  • c3b76e0 - Develop with Vue 3.5.45 while supporting consumers on Vue 3.2.47 and later Vue 3 releases. Preserve compatible component IDs and public declarations, and gate releases on packed runtime and type compatibility checks.

    The peer minimum is explicitly Vue 3.2.47. Consumers on Vue 3.2.0–3.2.46 must update to 3.2.47 or later in the Vue 3 line. No release is performed by this change.

Patch Changes

  • #6 6620155 Thanks @sparknest-team! - Keep a standard Textarea without a suffix within the field's width.

  • #6 6620155 Thanks @sparknest-team! - Fix keyboard listener types in Trigger while preserving Escape handling and listener cleanup across document windows.

  • Updated dependencies [6620155]:

    • @cedar-design/icons-vue@1.2.0
    • @cedar-design/shared-vue@1.2.0
    • @cedar-design/use-vue@1.2.0

  • #5 60c9c1a Thanks @sparknest-team! - Fix native form label targeting and nested field feedback, Cascader keyboard and search ownership, popup reference motion tracking, and inherited reading direction. Align Checkbox and Radio theme tokens and refresh their documentation.

  • #1 38eb17b Thanks @sparknest-team! - Close an open menu branch when another menu is opened from the keyboard.

  • #1 38eb17b Thanks @sparknest-team! - Remove patch-package from the published component library's runtime dependencies. Documentation-only dependency patches are managed by pnpm during development installation.

  • Updated dependencies [60c9c1a, c3b76e0]:

    • @cedar-design/use-vue@1.2.0
    • @cedar-design/icons-vue@1.2.0 permalink: /changelog/

Unreleased

Breaking Change

  • List / InfiniteScroll 与移动端 (maple-design-mobile) 完成分层：
    • List 收口为纯展示组件，移除 bottomOffset、reach-bottom 与 scroll-loading
    • size 仅保留 sm | md | lg
    • 无限加载改用独立 InfiniteScroll，以 v-model:status 管理 idle | loading | error | finished
  • Steps 与移动端 (maple-design-mobile) 完成 API 对齐：
    • 事件改为 listener prop：onChange / onUpdate:current（模板 @change / v-model:current 仍可用）
    • 抽出 props.ts，补齐 StepsProps / StepProps / StepStatus / StepsType 等类型导出
  • Alert 与移动端 (maple-design-mobile) 完成 API 对齐：
    • type="error" → type="danger"（与 Status 枚举统一）
    • type="normal" → type="default"
    • closeable → closable（拼写修正）
    • #close-element slot → #close-icon slot

Feature

  • 新增 InfiniteScroll：支持 bottomOffset、immediate、disabled、target、load / retry、check() / retry() 与同步防重。
  • Steps 修 vertical demo（direction="vertical"）、changeable demo（setCurrent 参数遮蔽）
  • Alert 新增 variant（standard / tonal / outlined）、color、elevation 属性；新增 default 类型；新增 after-close 事件。
  • Alert 样式重构为完全 CSS 变量驱动（style/token.less），覆盖 5 类型 × 3 变体颜色矩阵。
