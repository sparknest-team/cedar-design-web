## Cedar × Maple，同构的两端。

Cedar 是 Maple 的桌面端同构组件库。两端对齐组件 API、交互语义与设计 Token，让已有的组件使用经验延续到另一端，同时为鼠标、键盘与桌面布局提供合适的交互。

| | Cedar Design Web | Maple Design Mobile |
| --- | --- | --- |
| 面向场景 | 桌面端 · 鼠标与键盘 | 移动端 · 触控操作 |
| 组件约定 | 统一 API 与行为语义 | 统一 API 与行为语义 |
| 主题体系 | 语义 Token · 品牌定制 · 亮暗主题 | 语义 Token · 品牌定制 · 亮暗主题 |
| 开始探索 | 当前站点 | [前往 Maple ↗](https://maple.show) |

## 从 Cedar 开始

```shell
pnpm add @cedar-design/ui-vue
```

按照[快速上手](/guide/quickstart/)完成安装、组件引入和样式配置。移动端应用可前往 [Maple Design Mobile](https://maple.show)。
