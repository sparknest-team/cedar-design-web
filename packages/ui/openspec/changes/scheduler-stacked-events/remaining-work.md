# Scheduler 后续交互与权限清单

按当前源码审核，2026-09-11。下列为待实现或可优化项，并非已完成能力。

| 优先级 | 方向 | 当前能力与缺口 | 建议验收 |
| --- | --- | --- | --- |
| P1 | 操作级权限 | 有整体 readonly/disabled/loading、事件 readonly、禁用资源及提交钩子；没有查看/新建/编辑/移动/拉伸/删除/复制/分配的独立判定 | 统一能力解析器，返回允许及原因；工具栏、卡片、表单、拖拽、批量、撤销重做、实例方法复用；提交时再次验证 |
| P1 | 字段与资源权限 | event.readonly 是整条锁定，不能表达允许改标题但禁止改站/人/时间；资源 disabled 仅禁止新增关联 | 按动作和字段比较实际差异；先检查原始事件身份，防止通过 update 绕过移动/分配限制；保留旧关联、限制新增关联 |
| P1 | 权限失效与服务端一致性 | 异步保存能检查本地状态过期；没有角色/权限版本模型 | 请求等待时权限撤销，按权限版本拒绝；后端授权与原子资源校验；前端隐藏按钮不视为授权保障 |
| P1 | 拒绝解释 | 有统一错误/提醒与异步保存失败保留草稿；没有操作级禁用原因和拖动前诊断 | 禁用动作有可访问原因，预览直接说明资源/容量/权限问题；失败后焦点回到触发入口 |
| P2 | 重叠交互 | 本次提供固定偏移叠放、焦点前置、多选兼容 | 高密度重叠补充计数及列表入口；触屏提供无需双击的详情动作；屏幕阅读器播报重叠数量 |
| P2 | 键盘和触屏 | 空格/Enter 按钮、表单编辑与 Escape 取消已有；没有完整键盘移动/调整时长及触屏长按协议 | 方向键按吸附步长预览、Enter 确认、Escape 撤销；拖动和页面滚动手势区分；拉伸手柄可访问 |
| P2 | 编辑安全与历史 | 草稿保存、失败保留、原子事务/撤销重做已有 | 脏草稿关闭确认（按业务配置）、批量删除确认、撤销前权限重验、异步保存状态可追踪 |
| P2 | 时间与重复规则 | RRULE/IANA 适配器已有，网格仍本地时区；ICS 是明确子集 | 统一显示/编辑时区、重复小时轴和输入歧义提示；系列例外迁移、导入映射/预览及去重策略 |
| P2 | 大目录与依赖 | 行虚拟化和依赖校验已有；组合目录仍全量生成，依赖端点需加载 | 懒生成/分页资源组合、可取消计算；跨范围依赖查询和缺失端点提示；可选后继重排提案 |
| P3 | 真实协同与集成 | 内存 provider、expectedRevision、订阅取消已有 | 供应商鉴权、持久化、增量同步/重连、多人差异合并、审计记录；需要业务服务契约 |

建议先统一操作能力和差异判定，再接入各交互入口，最后完善键盘/触屏与高密度重叠体验。不要先只隐藏按钮，再单独补提交校验，避免规则不一致。
