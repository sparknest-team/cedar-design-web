# Tree scroll consumer classification

Tree only forwards public scrollIntoView options to actual VirtualList. Classify declaration and delegated-scroll separately, without adding a timer/CSS Token or repairing unchanged product code. Seven integration cases verify normal index/key alignment, replacement, inactive/disposed/queued correction, activation and nonvirtual no-op against existing child guards.

Actual Tree/VirtualList with stub TreeNode and simulated viewport/fixed sizes is JSDOM evidence, not native scroll/layout/OS or all Tree/loadMore lifecycle coverage. Maple guide only; no corresponding runtime created.
