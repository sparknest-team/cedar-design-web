# Scheduler 资源虚拟滚动

- 新增 virtualListProps?: SchedulerVirtualListProps，选取库内 VirtualListProps 的 height、estimatedSize、buffer 字段；仅资源时间线有效。未配置保持完整渲染。
- 默认视口高度 token --c-scheduler-virtual-height:480px，estimatedSize=80，buffer=10；后两者无效时回退默认。
- 分组标题与展开资源行形成稳定键序列，复用内部虚拟列表的变高测量。顶部时间刻度同步横向滚动。
- 事件先按真实资源建立索引，只计算被渲染行的事件布局并缓存。组合行取所有关联资源的交集，不改变主值或校验范围。
- 创建与拖动目标来自真实行映射。已挂载窗口内可拖动；指针源卸载取消，不支持自动跨窗口拖动。
- 日程、日期、刻度、筛选、展开分组及配置变化重建测量缓存并回到顶部。完整组合目录仍在内存中，不自动截断。

## 验收

千行目录只挂载有限窗口；滚动至第 900 行创建/移动仍使用其真实 ID；交叉行使用真实站与人 ID；折叠/过滤后无空白旧窗口；未开启虚拟滚动行为兼容。
