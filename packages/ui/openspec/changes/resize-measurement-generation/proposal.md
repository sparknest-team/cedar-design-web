# Measurement observer and frame generation ownership

Three reproduced independent Cedar/Maple failures: old dequeued RAF consumes replacement entries, disconnected observer injects old entries, pre-deactivation frame runs after reactivation. Separate binding/frame generations prevent cross-owner work without invalidating current observer notifications after a normal frame. Keep existing geometry updates, owner-window cancellation, API/defaults and CSS tokens.

Scoped Trigger simulations do not certify all consumers, same-node document adoption, pre-watcher target changes, real browser frames or OS preferences.
