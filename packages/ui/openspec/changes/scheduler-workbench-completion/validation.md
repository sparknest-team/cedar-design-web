## 合理取舍

- 业务页面组合三列和工具栏；组件不提供“出勤单”“工单状态”“技能”等专用属性。所有 DTO、接口模拟、校验和视觉规则均在 `__demos__`。
- 多任务关闭后，整单实际打卡区间按任务标准工时比例分配；示例不伪造后端不存在的逐任务实际打卡。
- 待办拖入已有单以任务内容区域为目标，同时提供详情中加入已勾选任务的键盘操作方式。
- 工单详情采用示例子弹窗；没有接入外部工单页面、真实账号权限和排班服务。
- Mock 保存与重载在当前页面会话内有效；刷新重新构造数据，不是持久数据库。生产接口仍需实现身份鉴权、版本校验、原子提交和数据加载。
- 旧专题 Demo 继续用于 API 示例；本次正式工作台是 `task-calendar-workbench.vue`，不要求其他专题复制全部业务。
